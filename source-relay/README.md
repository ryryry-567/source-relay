// 音源接力 · README

把 Folia 里的在线音源（网易云、酷狗、QQ 音乐，以及宿主或其它模组提供的音源）串成一条**接力链**：
一首歌在它自己的音源上放不了的时候，按你排的顺序去别的音源找同一首，接着放下去。

## 它解决什么

在 Folia 里换音源会先清掉当前播放和队列，还得确认登录的是哪个平台的账号。
这个模组换的不是「宿主当前音源」，而是「**这一首歌从哪个平台播**」：

- 歌在某平台要会员 / 已下架 / 要登录 / 播到一半断流 → 自动去下一个音源找同一首接着放，播放页不跳走。
- 播放器面板多一个「音源接力」标签页：这首歌在每个音源上的版本、时长、匹配度一列排开，点「播放」就换。
- 首页多一页「多源搜索」：搜一次，每个音源各出一组结果；可以绑全局快捷键，一键唤起、直接打字、回车就播。
- 一个命令（可以绑成全局快捷键）：`换一个音源播放`。歌在放着、不失败也能用。
- 宿主的音源选择、播放队列、登录状态**都不动**，不用重新登录、不用重新搜。

## 安装

1. 把整个 `source-relay` 文件夹放进 Folia 的模组目录：
   - Windows：`%APPDATA%\Folia\mods\source-relay`
   - 或者打开「设置 → 模组 → 打开模组目录」，把文件夹放进去。
2. 「设置 → 模组」里确认「模组系统」已开启，然后点模组的「重载」。
3. 启用「音源接力」，在系统确认窗口里点允许（它会用你的账号去各平台搜歌，说明写在确认窗口里）。
4. 播放器面板 → 拼图标签 → 「音源接力」；首页导航末尾 → 「多源搜索」。

## 用法

| 想做的事 | 怎么做 |
| --- | --- |
| 放不了自动换 | 默认开着。设置里可关。 |
| 手动换一个源 | 命令面板搜「换一个音源播放」，或面板里点「换一个音源播放」。 |
| 指定用哪个源放 | 面板里那一行点「播放」。 |
| 一次搜所有音源 | 首页「多源搜索」：打一个字就出结果，点任意一行就播。 |
| 把它当搜索框用 | 「设置 → 快捷操作 → 全局快捷键」给「多源搜索」绑一个键：以后按一下就在输入框里，打完回车。 |
| 调整接力顺序 | 面板底部「接力顺序」：▲▼ 调先后，取消勾选就跳过该音源。顺序会记住，多源搜索也按这个顺序排。 |
| 不在前台也能换源 | 同上，给「换一个音源播放」绑一个键。 |

### 多源搜索能替代自带搜索框到什么程度

Folia 的搜索浮层没有对模组开放的钩子（模组能挂的只有歌词、播放前、音源解析这几个），
模组也改不了「宿主当前选中的音源」，所以**没法把多源结果塞进它自己的搜索框**。
能做的是最接近的替代品：

- 用全局快捷键一键唤起（Folia 在后台也能按），打开就是输入框，边打边搜（350ms 防抖）；
- 结果按音源分组、按你的接力顺序排，↑↓ 跨音源连续选，回车播，Esc 清空；
- 每行都能「播放 / 入队」，放的是那一行自己平台的那一版，不用先切音源。

## 匹配怎么做的

1. 搜索词 `歌名 主歌手`；搜不到时再用去掉 `(Live)`、`- Remastered` 这类版本后缀的歌名搜一次。
2. 每条结果打分：歌名 60%（去标点、全半角归一、去版本后缀后做二元组相似度）、歌手 28%（按 `/`、`&`、`、` 拆词比较，候选多带合作者不算错，缺歌手要扣分）、时长 12%（差 2 秒内满分，差 25 秒以上零分）。
3. 分数 ≥ 75% 且歌名 ≥ 62% 才算「同一首」；低于这个线宁可不放，也不会把别人的歌顶上来。
4. 音源顺序优先：只有排在前面、分数又没落后 6 个百分点以上的音源才会被抢先。
5. 下架标记的候选直接排除；一次接力链上同一首不会绕回去（A→B→C 到顶就停）。

## 边界

- **每个音源仍然要在 Folia 里登录过一次**，模组才能用它搜索、播放；之后不用再来回切账号。
- 搜索走 `folium.omni`，以你的账号发请求，按模组限速（约 120 次/分钟，一次多源搜索 = 每个音源 1 次）；
  面板打开时只查当前这一首，缓存 90 秒。
- 不替换队列里的条目：接力只换当前正在播的那一版，队列继续按原样往下走。
- 不做也不该做「导出音频流」这类事。
- 只在桌面版 Folia 0.7.x（Folium 1.7+）上可用；网页版 / PWA 没有模组系统。
